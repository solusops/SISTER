# Figures Directory

Store image and figure assets for the paper here.

## Recommended Practices
1. **Vector formats preferred**: Use PDF (`.pdf`) or EPS (`.eps`) for diagrams, plots, and charts so they scale sharply without pixelation.
2. **Raster formats**: For photos or complex rendered heatmaps, use high-resolution PNG (`.png`, at least 300 DPI).
3. **Naming**: Use lowercase underscore-separated names (e.g. `overview.pdf`, `ablation_curve.pdf`).
4. **Standalone TikZ**: For complex TikZ diagrams, consider placing the `.tex` source in this folder and compiling to a `.pdf` standalone figure so main paper build times stay fast.
